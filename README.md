# 🚗 Vehicle License Registration System

## 📌 About the Project

The **Vehicle License Registration System** is a web-based application designed to modernize and simplify vehicle license registration. It allows clients to create accounts, submit vehicle registration applications, and receive unique application reference numbers. Administrators and authorized officers can review applications and manage license plate issuance, improving accuracy, security, and efficiency.

## ✨ Key Features

- **User Authentication:** Clients can create accounts and securely access the system.
- **Online Registration:** Submit vehicle license registration applications.
- **Unique Application ID:** Generate a reference number for each application.
- **License Plate Generation:** Generate license plates after application approval.
- **Duplicate Prevention:** Prevent duplicate registration applications and license plate records.
- **Role-Based Access:** Separate access for administrators, officers, and clerks.
- **Vehicle Classification:** Support private vehicles, commercial vehicles, and motorcycles with different plate colors.
- **Application Management:** Review and manage submitted applications throughout the registration process.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL / MariaDB
- **Development Environment:** XAMPP
- **Database Management:** phpMyAdmin

## ⚙️ How It Works

1. **Create an Account:** Clients register and log in to the system.
2. **Submit an Application:** Clients provide the required vehicle and registration information.
3. **Receive a Reference ID:** The system generates a unique application number.
4. **Review and Approval:** Authorized personnel review the application and approve eligible registrations.
5. **Generate License Plate:** The system generates a plate number after approval.
6. **Manage Records:** Authorized users manage registration information and prevent duplicate records.

## 🚘 License Plate Classification

- **Private Vehicles:** Orange license plates.
- **Commercial Vehicles:** Yellow license plates.
- **Motorcycles:** Blue license plates with randomly generated five-digit numbers.

*Note: Plate colors and numbering follow the classification rules implemented in this project.*

## 💻 Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin and create the required database.
6. Import the project's SQL database file, if included.
7. Configure the database connection settings in the project.
8. Open your browser and navigate to `http://localhost/CAR%20LESSONS` or the appropriate URL for your project folder.
